## 🎨 Design & Features (Replicating Reference Screenshots)

1. **Floating Pill Navigation Bar:**
   - Translucent glassmorphic pill header with subtle shadow.
   - Links: `HOME`, `MENU`, `EXPERIENCE`, `REVIEWS`, `FAQS`.
   - Authentic **Kadai steam logo mark** and typography.
   - `RESERVE NOW` pill action button and direct `ORDER ONLINE` link.

2. **Hero Section & Live Status Badge:**
   - Full-bleed ambient slider carousel with auto-rotation, indicators, and pause-on-hover.
   - Floating live status badge at bottom-left: `NOW OPEN — Monday–Sunday · 12:00 PM – 12:30 AM ➔` with live time status calculation.

3. **Editorial Grand Serif Typography:**
   - Eyebrow: `Welcome to The Kadai Story`
   - Headline: `Raising the Calibre of Authentic Multi-Cuisine Dining in Nagole`
   - Trust strip with Google 4.0 ★ rating and per-person price badge.

4. **Symmetrical Rounded Feature Cards (28px border-radius):**
   - **Card 1: Curated Menu** with `CLICK TO VIEW` button that triggers the full interactive menu drawer and search modal.
   - **Card 2: Indulgent Dining & Feasts** showcasing the signature **Circular Wooden Dining Pods**, warm ambient pendant fixtures, and spacious family seating.

5. **Signature Dish Highlights & Filter Tabs:**
   - Mutton Potlam Keema Biryani (Wrapped in thin omelette pouch)
   - Chicken Dum Biryani
   - Pandu Mirchi Chicken Fry
   - Miryala Kodi Vepudu (Black Pepper Chicken)
   - Baby Corn Kurkure South Indian Style
   - Chicken Tikka Masala Soup
   - Kadai Special Murgh / Paneer
   - Freshly Baked Butter & Garlic Naan

6. **Interactive Reservation Modal:**
   - Guests selection (2 to 10+), date picker, lunch/dinner time slots, seating preferences (Circular Pods, Family Booth, Main Hall).
   - Generates instant verified booking reference code (`TKS-XXXXX`).

7. **Location & Contact Hub:**
   - Direct integration with the user's exact Google Maps place link.
   - Direct click-to-call `tel:08383883939`.
   - Google Order Online integration.

## 🚀 How to Open and View

### Option 1: Direct File
Double-click `index.html` or open it in Google Chrome, Microsoft Edge, or any modern web browser.

### Option 2: Local HTTP Server
Run the local server in this directory:
```powershell
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
